Theme Editor

Preview every SampleBoot screen as the MPC Sample draws it, change the settings and colours, then copy the generated sampleboot.conf into autorun/sampleboot/ on the SD card. Everything runs in this page: nothing is sent anywhere.

Preview

The MPC Sample's panel shows 65,536 colours (16-bit RGB565: 32 levels of red, 64 of green, 32 of blue). With the checkbox on, the preview rounds every colour the same way. Brightness and viewing angle of the real screen still make colours look a little different: check the result on the device.

Start from

Paste your current sampleboot.conf to start from your own values. Without it, the editor starts from the original values.

Ready-made themes

A theme changes the colours only; the behaviour settings stay as they are.
